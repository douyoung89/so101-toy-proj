# 공개 사본 검증 · 2026-11-02

기존 macOS arm64의 Python 3.12 `so101` 환경에서 아래 항목을 실제로 확인했습니다. 새 가상환경 설치와 외부 네트워크 다운로드는 이번 검사에 포함하지 않았습니다.

| 검사 | 결과 |
|---|---|
| 공개 파일 SHA-256 목록 | 검증 통과 |
| 원본 best.pt의 selection 해시 | 일치 |
| 저장된 특징의 분류 재현 | train 81/81 · val 14/14 · test 5/5 |
| 같은 학습 코드로 특징 재학습 | epoch 400 선택, state_dict의 모든 텐서가 원본과 정확히 일치 |
| 방향 교사·인과 입력·학습 프로토콜 테스트 | 13개 통과, 원본 saved-run 프레임 감사 1개 건너뜀 |
| 기억·BFS·에피소드·물리 안전 테스트 | 10개 통과 |
| 새 데이터 초기화 | 2개 장면 계획·설정 생성 통과 |
| 배포 Python 소스 구문 | 전체 통과 |
| 저장된 MP4 | 305프레임 전체 디코딩, 1280×720, 20fps, 15.25초 |
| 로컬 Markdown 파일 링크 | 누락 없음 |

물리 테스트에는 기존 로컬 외부 모델의 복사본을 사용했습니다. 이 외부 모델·테스트 출력·캐시는 Git에서 제외했습니다. 기준 XML의 경로를 현재 위치로 채우는 생성 과정과 렌더링 없는 물리 이동은 검증했습니다.

새 GUI 시연·새 영상 촬영·전체 데이터 재수집·새 온라인 test는 이번 공개 정리 작업에서 실행하지 않았습니다. 대표 영상은 기존 val 실행의 원본을 포함했습니다. 과거 보고서에 적힌 수집·온라인 평가 성능은 보존된 결과 기록이며 이번 재실행 결과와 구분합니다.

전체 원본 프레임은 공개하지 않으므로 과거 저장 영상 해시 감사 테스트 1개는 건너뜁니다. 파일럿의 과거 원본 무변경 감사와 픽셀 재현을 이 축약본에서 새로 검증했다고 주장하지 않습니다.

`requirements.txt`는 특징 학습용 직접 의존성, `requirements-sim.txt`는 시뮬레이션 추가 의존성입니다. 기존 환경의 전체 패키지 목록은 `original-environment.txt`에 참고 기록했습니다.
