# SO-101 partial v1 파일럿 결과

`so101/`에 새 코드·설계·데이터·검수 결과를 모았습니다. 기존 루트 실험 자료는 보존합니다.

## 수집과 검증

- 후보 33개 중 15개 장면 채택: 각도별 원본 345장과 OCR 345건, 224×224 파생 영상 별도 저장.
- 거절 후보 18개는 원본 영상·OCR·XML·거절 원인과 함께 `data/partial_v1/rejected/`에 보존.
- 네 수집 전략으로 실제 이동·새 촬영·OCR을 실행한 에피소드 60개 완료. 영상 재사용 없음.
- 최종 감사: 기술적 오류 0개, 분할 중복 0개, 제외 에피소드 0개. 15개 장면의 모든 각도 물리 상태 재현 통과.
- 테스트 10개 통과. OCR 기억·충돌 재확인·이동 예산·미래 입력 제외·파일 변조 탐지·실제 물리 이동 확인.
- 영상의 픽셀 동일성은 검증하지 않았으며 경로 간 영상 재사용도 활성화하지 않음.

## 수집 경로별 결과

| 전략 | 정확한 두 값 확보 | 잘못된 STOP | 평균 이동 |
|---|---:|---:|---:|
| left_first | 7/15 | 0 | 5.73 |
| right_first | 8/15 | 1 | 5.40 |
| random | 6/15 | 0 | 6.13 |
| shortest | 15/15 | 0 | 3.60 |

전체 36/60(60%)가 두 값을 정확히 확보했습니다. OCR 오독 1건은 당류 2 g을 20 g으로 읽은 경우이며,
이로 인한 잘못된 STOP 1건도 보존했습니다. 실패 기록을 삭제해 성공률을 높이지 않았습니다.
최단 경로 전략은 관측표를 이용하는 수집용 oracle이므로 정책의 최종 평가 성능과 구분해야 합니다.

## 분포와 범위 판단

- 선택 시작점: 최단 1회 2개, 2~3회 6개, 4~6회 6개, 7~8회 1개.
- 유리한 첫 방향: 왼쪽 7개, 오른쪽 8개.
- 5° 간격과 최대 8회 이동은 다음 파일럿에서도 유지할 근거가 있습니다. 8회가 필요한 장면 1개를 보존했습니다.
- 현재 시작 후보 −30°~+25°는 유지하되 1회 해결 사례를 더 확보해 20/40/40 목표를 다시 확인해야 합니다.
- 모든 거절 후보에서 안전 경로를 포함한 해결 가능한 시작점이 없었고, 그중 14개는 각도 또는 이동 안전 검사도 실패했습니다.
- 다음 생성에서는 가로 폭을 기준의 0.9~1.02배로 좁히는 것을 제안합니다. 고정 hood 안쪽 경계가 ±0.029 m이고,
  기준 가림판 반폭이 0.028 m라서 1.1배 후보는 형상 겹침을 만들 수 있습니다. 현재 데이터의 범위를 사후 변경하지 않았습니다.
- 선택 시작점 중 1개(scene_000005)는 두 텍스트 사각형의 모든 광선 표본이 노출되어 있었지만 OCR 기억이 불완전했습니다.
  나머지 14개와 구분해 OCR 제약 사례로 해석해야 합니다. 광선 표본은 글자 판독 가능성을 완전히 보장하지 않습니다.
- 기존 가림판에는 이동 한계가 없었습니다. 새 한계와 포화 연동 방식은 README에 실제 단위와 함께 명시했습니다.

## 학습 입력과 평가 범위

학습 입력은 train 284건 / val 46건 / test 20건, 총 350건입니다.
입력 필드 허용 목록·과거 관측 수·이미지 경로를 재검사했습니다. 정답·가림판 설정·미래 관측은 input에 없습니다.
기술적 결함이 없는 오독과 탐색 실패는 남아 있으므로 행동 모방 대상의 품질을 metadata와 원본 에피소드로 구분할 수 있습니다.

개발용 test 시작점 1개에서 고정 순회·좌측 우선·우측 우선·무작위와 미학습 예시 정책을
새 MuJoCo 영상/OCR로 실행했습니다. 예시 정책은 실제 이미지 파일을 열고 콜백으로 행동을 선택하며,
3회 이동 후 두 값을 정확히 확보했습니다. 이는 평가 연결 검사이며 학습된 정책의 성능 주장이 아닙니다.
기존 라벨은 이전 개발 실험에 사용됐으므로 미사용 라벨의 최종 평가는 아직 수행되지 않았습니다.
최종 평가에는 별도로 잠근 새 라벨·가림판 설정과 학습된 정책이 필요합니다.
