# 2026-11-02 개발 파일럿 기록

`data/`는 재라벨·중복 병합한 81/14/5개 구조화 상태와 제외 로그입니다. 원본 이미지 없이 CPU 학습에 사용할 수 있습니다.
`best.pt`는 원본 체크포인트이며 `selection.json`의 SHA-256으로 확인합니다.
`evaluation/`에는 15개 온라인 에피소드의 관측/OCR/행동 기록만 보존했습니다. 기록이 가리키는 프레임은 용량 절감을 위해 제외했습니다.

`REPORT.md`와 로그는 과거 실행 기록입니다. `$ORIGINAL_PROJECT`는 원래 체크아웃을 뜻하며 실행 경로가 아닙니다.
절대 경로를 익명화해 일부 JSON의 과거 파일 해시는 공개본과 달라질 수 있습니다. 이미지 해시나 과거 소스 보존 감사를 이 축약본에서 재검증할 수는 없습니다.
소스 스냅샷·전체 source_inventory·중복 프레임은 제외했습니다. 새 수집과 전체 평가는 루트 README를 따릅니다.
